# Why Linear Code Generation Fails

- **The Linear Prompting Trap**:
  - Standard coding agents use linear chat chains:
    $$\text{Draft} \to \text{Error} \to \text{Retry} \to \text{Error} \to \text{Plateau}$$
  - No concept of branching: a bad decision poisons the context window.
  - No backtracking: the agent cannot revert to a known good state.

- **The AIDE2 Solution**:
  - Treat program generation as a **Monte Carlo Tree Search (MCTS)** over code space.
  - Nodes represent complete, compilable Python strategy programs.
  - Edges represent discrete operator mutations.
  - Prune dead-ends and backtrack dynamically when code crashes or drawdowns spike.

```
+---------------------------------------------------------------------------------+
```

# Data Structure: The StrategyNode

Implemented in `02_aide2/tree_node.py`:

```python
class StrategyNode:
    def __init__(self, node_id: str, code: str, metrics: BacktestResult, parent=None):
        self.node_id = node_id
        self.code = code                # Complete executable Python source code
        self.metrics = metrics          # Ground-truth backtest metrics (Sharpe, MDD)
        self.parent = parent
        self.children: List[StrategyNode] = []
        self.visits: int = 0            # N(n)
        self.total_value: float = 0.0   # Q(n)
        self.is_dead_end: bool = False
```

- Encapsulates code, execution metrics, and tree search topology in one unit.

# The Three Specialized Operators

Implemented in `02_aide2/operators.py`:

1. **Drafting Operator ($O_{\text{draft}}$)**
   - Synthesizes baseline strategy code from high-level natural language intent.
   - Generates classes inheriting from `BaseStrategy`.
2. **Debugging Operator ($O_{\text{debug}}$)**
   - Intercepts compiler errors, runtime exceptions, and numerical failures.
   - Applies AST-guided surgical repairs.
3. **Refinement Operator ($O_{\text{refine}}$)**
   - Fine-tunes moving average windows, volatility filters, and threshold parameters.

# Step B & C: Automated Exception Interception & AST Repair

Suppose candidate code introduces an unhandled division:
```

--> Traceback Log Snippet:

      return self._compiled_strategy.generate_signals(market_data)
```

The `DebuggingOperator` catches the traceback and repairs the AST:
```python
# Before (Buggy Code):
ret = (price_t - price_prev) / (volatility)

# After (Debugging Operator Surgical Repair):
ret = (price_t - price_prev) / (volatility + 1e-8)
```
- Backtest passes immediately: Sharpe **0.8712**, Zero Crashes!

# Step D: UCT Selection & Adaptive Backtracking

Implemented in `02_aide2/mcts_search.py`:

$$\text{UCT}(n) = \frac{Q(n)}{N(n)} + c \sqrt{\frac{\ln N(\text{parent})}{N(n)}}$$
